# 恋爱脑克星

这是一个专为“恋爱脑”上头人群打造的自救计划。灵感来自星座解读和情感博主陶白白的轻松语气，我们把情绪疗愈做成一场好玩的“宇宙心灵旅行”。

## 整体玩法：十二星座宇宙补给站
- **情绪星盘扫描**：进入小程序后，先填写一份“恋爱脑体质”问卷，系统会像占星师一样分析你的情绪起伏频率、危机触发点和自我价值感指数。
- **星座补给包**：结合你选定的星座人格标签（不必真实生日，只挑选“当下的自己”），推送三种能量包：
  1. **理智守护星**：提供秒醒语录、陶白白式理性分析语音，让你在想发消息前先停顿三秒。
  2. **自爱力场**：推送自我对话练习、日记模版和“我今天为自己做了什么好事”的打卡页面。
  3. **社交星际站**：匹配同频的“清醒队友”，开启三分钟语音互助或匿名心情交换，感受群体陪伴。
- **恋爱脑预警雷达**：根据你的互动记录（如打卡频率、情绪波动），生成一条“今日宇宙预报”，用陶白白式幽默提醒你：
  > “今日偏爱自我，少管别人的银河系。想发消息？先问问你的理智守护星同不同意。”

## 模块亮点
- **星座式互动设计**：每个星座房间都有独特的反恋爱脑任务，例如：
  - 白羊：冲动止损 30 秒倒计时，完成后才允许回复。
  - 巨蟹：情绪寄存柜，把敏感瞬间存入“月光瓶”，第二天再打开。
  - 狮子：自信放大镜，用语音教练带你夸自己。
- **陶白白语气包**：所有提示文字保持“搞怪又扎心”的风格，例如：
  > “别再翻聊天记录啦，你的前任已经过期，宇宙建议你回收利用。”
- **能量条可视化**：以星座能量条呈现自我关注、社交需求、情绪稳定三个维度，看到能量下降时自动跳出练习提醒。

## 使用方式
1. 选择当下最贴合心情的星座标签。
2. 完成情绪星盘扫描，获取个性化补给包。
3. 按照每日任务打卡并记录感受，持续 21 天形成“恋爱脑免疫力”。
4. 邀请好友一起加入星际队伍，互相监督与鼓励。

## 目标
- 帮助你在轻松有趣的体验中重新发现自我价值。
- 建立长期的情绪自我照顾习惯。
- 把恋爱脑转化为爱自己的能量，让“恋爱脑克星”成为你的宇宙陪练。
