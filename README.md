# 恋爱脑克星 · 互动网站

“恋爱脑克星”现在变成了一个可以直接在浏览器体验的互动网站，让你在星座宇宙的设定中完成情绪扫描、领取专属补给包，并坚持 21 天自我陪练计划。

## 在线体验

### 如果你完全没有写代码的经验，也可以照着下面做：

1. **下载项目**  
   - 打开浏览器访问项目页面，点击绿色的 **Code** 按钮。  
   - 选择 **Download ZIP**，浏览器会把压缩包下载到你的电脑里（通常在“下载”文件夹）。
2. **解压压缩包**  
   - 在 Windows 上：右键压缩包，选择“全部提取”；在 macOS 上：双击压缩包即可自动解压。  
   - 记住解压后的文件夹位置，例如 `C:\Users\你的名字\Downloads\Cure-for-lovesickness-main`。
3. **打开网站**  
   - 在解压后的文件夹里找到 `index.html` 文件。  
   - 直接双击它，电脑会用默认浏览器打开，你就能看到网站界面。  
   - 如果双击没有反应，可以右键选择“打开方式”，再手动选一个浏览器（例如 Chrome、Edge、Safari）。
4. **开始体验**  
   - 页面加载后，不需要登录或安装任何东西，所有互动（选择星座、打卡、生成建议）都在浏览器里完成。  
   - 浏览器会自动保存你的打卡记录；如果想重新开始，可以点击页面上的“重置”按钮。

> 想在手机上体验？可以把整个解压后的文件夹复制到手机里，再用手机自带浏览器打开 `index.html`，同样可以使用主要功能。

无需额外安装或配置，特别适合自称“计算机小白”的你。

## 网站亮点

### 1. 情绪星盘扫描
- 滑动刻度评估“想Ta冲动值”“自我关注能量”“情绪波动幅度”。
- 一键生成今日宇宙预报，搭配陶白白式醒脑金句。

### 2. 星座补给包
- 12 个星座任你选，不拘生日，只选当下的自己。
- 自动推送三大补给：理智守护星、自爱力场、社交星际站。
- 设计语言延续搞怪又扎心的语气，方便截图分享。

### 3. 21 天宇宙陪练计划
- 按阶段拆解：Day 1-7 理智守护、Day 8-14 自爱强化、Day 15-21 社交巡航。
- 提供可勾选的每日打卡清单，进度会自动保存在浏览器。
- 支持一键重置，随时开始新的挑战。

### 4. 新手友好 FAQ
- 回答常见问题：是否需要安装、如何保存打卡、如何分享补给包。
- 打造真正无需门槛的宇宙自救站。
